# GYMDS

GYMDS is a gym management desktop application currently being developed using C#, Windows Forms, and MySQL.

The goal of the project is to create a system that helps manage gym members, memberships, workout plans, payments, and other gym-related operations in a simple and efficient way.

This project is still under development and is not the final version.

---

## Current Features

- User registration
- Login authentication
- Membership plan selection
- Workout plan selection
- MySQL database integration
- Data storage and retrieval
- Multi-form navigation

---

## Planned Features

- Admin dashboard
- Payment management
- Progress tracking
- Reports and analytics
- Booking system
- Improved UI/UX
- Member profile management
